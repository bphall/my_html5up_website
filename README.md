# braytonhall.com

Hand-built personal site: one HTML file, no framework, no build step, no tracker.

- `index.html` — the whole site (CSS and JS inline)
- `model.js` — the Tolstoy machine: a trigram model of War and Peace (10,438-word
  vocabulary), built by `build_model.py` from the Project Gutenberg text
- `assets/Brayton_Hall_Resume.pdf` — current resume (Feb 2026)
- `images/` — photos

Deploys via GitHub Pages from `master`. `CNAME` = braytonhall.com.
